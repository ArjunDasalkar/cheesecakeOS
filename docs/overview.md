# Project Overview

## Introduction

Cheesecake OS is a minimal operating system kernel designed to understand and implement core operating system concepts from scratch.

The project focuses on low-level programming and system design, bridging the gap between hardware and software.

---

## Objectives

- Understand how an OS interacts with hardware
- Implement core kernel components
- Gain experience with systems programming
- Build a structured and modular codebase

---

## Key Features

- Bootable kernel using GRUB
- Direct hardware interaction (VGA output)
- Interrupt handling system
- Basic device drivers
- Memory management
- Command-line shell

---

## Development Environment

- WSL (Linux environment)
- GCC (32-bit support)
- NASM
- QEMU Emulator
- GRUB Bootloader
